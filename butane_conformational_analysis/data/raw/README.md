In this directory ther're the n-butane files.
- The molecular file was generated and minimization thanks to Avogadro software.The force field used for this first description is MMFF94 (default setting).
- The second describes the torsional angles of the molecule before ab-initio optimization.
- The bond_distances file contains C-C and C-H distances in Angstrom.
- The total energy calculated using MMFF94 is -21.2371 eV.
- The total force norm calculated using MMFF94 is 0.346321 Kcal/mol*Angstrom (= 1.44900 +/- 0.00001 KJ/mol*Angstrom).
