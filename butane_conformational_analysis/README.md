# Butane Conformational Analysis

## Objective

Study the relationship between the
C-C-C-C dihedral angle and the conformational
energy of n-butane.

## Project goals

The project will develop a reproducible workflow
for analysing computational chemistry data.

## Tools

- Python
- Bash
- NumPy
- Pandas
- SciPy
- Matplotlib
- Git

## Workflow

Computational data
- extraction
- processing
- analysis
- visualization
- scientific interpretation
